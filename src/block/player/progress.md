# 过程描述

## 判定圈运动过程

判定圈在轨道上来回运动

### 流速的含义

流速为判定圈每秒移动的像素数
判定圈每秒移动 $1 \times speed$ 个像素
其中 $speed$ 是流速

## 音符生成过程

音符在其所属的轨道上，需要生成的音符满足以下几个条件

- 没有被完全判定
- 在判定圈运动中的剩余路程中或在下一次折返的路程中
- 不会遮挡其他在同一轨道中已经渲染的音符

音符判定的过程

1. 每一帧均要执行，获取所有的有效输入
2. 获取所有的还未被判定的音符，按照时间顺序排序，从前到后
3. 判定所有的音杠：如果现在有有效输入，所有音符进行判定
4. 判定所有的音点：对于每一个音符，如果现在有有效输入，消耗一个有效输入，进行判定
5. 判定所有的长弦：对于每一个音符，如果现在有有效输入，消耗一个有效输入，进行判定
6. 判定所有的尾键：对于每一个音符，如果现在的有效输入数量比上一次少1，增加一个有效输入，进行判定
7. 根据判定规则，进行后续操作

## 判定规则

提前说明

- 所有的区间均为上闭下开
- 省略符号/正号的数值为音符打击节拍在乐曲节拍之后多出的毫秒数
- 负号的数值为音符打击节拍在乐曲节拍之前少的毫秒数

### 音点的判定

判定区间

| 判定结果 | 上区间 | 下区间 | 额外说明                    |
| -------- | ------ | ------ | --------------------------- |
| Perfect  | 50     | -50    |                             |
| Early    | 80     | 50     | 与Late同属于Early/Late判定  |
| Late     | -50    | -80    | 与Early同属于Early/Late判定 |
| +Good    | 120    | 80     | 与-Good同属于Good判定       |
| -Good    | -80    | 120    | 与+Good同属于Good判定       |
| Miss     | -120   |        |                             |

### 音杠的判定

判定区间

| 判定结果 | 上区间 | 下区间 | 额外说明 |
| -------- | ------ | ------ | -------- |
| Perfect  | 50     | -120   |          |
| Miss     | -120   |        |          |

### 长弦的判定

头部判定同音点

中间段每64ms判定一次
有效输入：Last
无效输入：Break

### 尾键的判定

判定区间

| 判定结果 | 上区间 | 下区间 | 额外说明 |
| -------- | ------ | ------ | -------- |
| Perfect  | 100    | -100   |          |
| Miss     | -100   |        |          |

### Acc的计算

Acc基准值为100%，根据不同的判定结果进行扣除

Perfect、Early/Late、Last：不扣除
Good：扣除 $100\% / sum \times 50\%$ 的Acc
Break：扣除 $100\% / sum \times 10\%$ 的Acc
Miss：扣除 $100\% / sum$ 的Acc
其中， $sum$ 是总物量

## 幻想值

幻想值分为三个部分

### 幻想点数

根据不同判定改变点数
Perfect：增加2点
Early/Late：增加1点
Break：减少1点
Miss：减少5点

### 负幻想点数

当幻想点数到达下限时（默认 0 点），继续扣除幻想点数不减少，改为扣除负幻想点数
当负幻想点数到达上限时（默认 0 点），继续增加负幻想点数不增加，改为增加幻想点数

根据不同判定改变点数
Perfect、Early/Late：增加1点
Miss：减少2点

当负幻想点数达到下限时（默认 -5 点），进入幻死亡状态，如果没有特殊效果，则强制终止乐曲并立即结算

### 溢出幻想点数

当幻想点数到达上限时（默认 100 点），继续增加幻想点数不增加，改为增加溢出幻想点数
当溢出幻想点数到达下限时（默认 0 点），继续扣除溢出幻想点数不减少，改为扣除幻想点数

根据不同判定改变点数
Perfect、Early/Late：增加10点
Good：增加8点
Last：增加1点
Break：减少1点
Miss：减少10点

当溢出幻想点数达到上限时（默认 90 点），进入幻永生状态
单个关卡中，只要进入幻永生状态就不会退出，即使溢出幻想点数低于其上限值
幻永生状态不会改变幻想值的累计规则，但会改变判定规则
所有Early/Late判定转化成Perfect判定

## 关卡结算

### 幻想值结算

根据幻想值的多少决定结算评级颜色
从高到低如下

彩色：达成幻永生
金色：$pt \ge 80$
紫色：$60 \le pt < 80$
蓝色：$40 \le pt < 60$
绿色：$20 \le pt < 40$
黑色：$pt < 20$
白色：达成幻死亡

其中 $pt$ 为幻想点数，数字为占幻想点数上限值的比值

### Acc结算

根据Acc的多少决定评级
从低到高

SB：$Acc < 30\%$
FL：$30\% \le Acc < 60\%$
UG：$60\% \le Acc < 70\%$
GD：$70\% \le Acc < 80\%$
VG：$80\% \le Acc < 95\%$
SG：$95\% \le Acc < 100\%$
AP：$Acc = 100\%$
特别的，当一首曲子的Perfect判定数和物量相等时，有特殊判定EX，同时Acc强制改为101%
